# Restaurant

A Flutter restaurant ordering and bill desk app for browsing menus, placing orders, and managing restaurant orders.

## Features

- Browse categorized food and drink menus
- Place delivery and hotel/table booking orders
- Track and manage orders in the bill desk
- Save menu and order data locally, with optional Firebase menu and alert sync
- Take payments through Razorpay (configure a valid key before enabling payments)

## Tech stack

- Flutter and Dart
- Firebase Core and Cloud Firestore
- Razorpay Flutter, shared preferences, image picker, URL launcher, sharing, and local notifications

## Getting started

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) and the Android toolchain.
2. Clone this repository and change into its directory.
3. Install dependencies:

   ```sh
   flutter pub get
   ```

4. Configure Firebase for your own project if you need cloud sync. Keep private credentials and signing keys out of source control. Set a valid Razorpay key using your chosen secure configuration before accepting payments.
5. Run the app:

   ```sh
   flutter run
   ```
